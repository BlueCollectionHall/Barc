## 三-A、后端架构模式

### 3-A.1 语义化响应类（response 包）

**不要直接 `new J()`，使用预定义的语义化响应类！**

| 类名 | 用途 | 使用场景 |
|------|------|---------|
| `ResourceR` | 资源获取响应 | 查询数据成功/失败 |
| `ChangeR` | 变更操作响应 | 上传、删除、修改操作 |
| `UserR` | 用户错误响应 | 用户不存在、权限不足、UUID不匹配 |
| `SuccessR` | 通用成功响应 | 简单成功操作 |
| `ErrorR` | 通用错误响应 | 简单失败操作 |
| `J` | 基础响应类 | 以上都不满足时使用 |

#### ResourceR - 资源获取

```java
// 获取资源成功/失败
return ResponseEntity.ok(new ResourceR().resourceSuch(true, data));
return ResponseEntity.ok(new ResourceR().resourceSuch(false, null));
```

#### ChangeR - 变更操作

```java
// type: 1=上传, 2=删除, 3=修改
return ResponseEntity.ok(new ChangeR().udu(true, 1));  // 上传成功
return ResponseEntity.ok(new ChangeR().udu(false, 2)); // 删除失败
```

#### UserR - 用户错误

```java
return ResponseEntity.ok(new UserR().noSuchUser());              // 用户不存在
return ResponseEntity.ok(new UserR().insufficientAccountPermission()); // 权限不足
return ResponseEntity.ok(new UserR().uuidMismatch());            // UUID不匹配
```

### 3-A.2 DTO 类（utils/dto 包）

| 类名 | 用途 |
|------|------|
| `PageRequestDto` | 分页查询请求参数 |
| `PageResultDto` | 分页查询结果 |
| `ValueLabelDto` | 键值对（用于下拉选项） |

#### PageRequestDto - 分页请求

```java
@Data
public class PageRequestDto {
    private Integer page_num = 1;      // 当前页码
    private Integer page_size = 10;    // 每页条数
    private String sort_field;          // 排序字段
    private String sort_order;          // 排序方向
    private Map<String, Object> params; // 查询参数
}

// Controller 使用
@PostMapping("/list")
public ResponseEntity<J> getList(@RequestBody PageRequestDto dto) { }
```

#### ValueLabelDto - 键值对

```java
// 用于下拉选项
new ValueLabelDto(value, label);

// 示例：获取权限选项
return ResponseEntity.ok(new ResourceR().resourceSuch(true, PermissionConst.getOptions()));
```

### 3-A.3 后端分层职责

| 层级 | 目录 | 职责 |
|------|------|------|
| Controller | `*/controller/` | 接收请求、参数校验、调用 Service |
| Service | `*/service/` | 业务逻辑处理 |
| Mapper | `*/mapper/` | 数据库操作 |
| Model | `*/model/` | 数据模型（数据库表映射） |
| DTO | `utils/dto/` | 数据传输对象 |
| Response | `response/` | 统一响应封装 |
| Annotation | `annotation/` | 自定义注解 |

### 3-A.4 后端开发规范

1. **Controller 注解**：使用 `@RestController`，路径用 `@RequestMapping`
2. **公开接口**：方法上加 `@IgnoreAuth` 注解
3. **权限控制**：方法上加 `@RequireUserAndPermissionAnno` 注解
4. **响应封装**：优先使用 `ResourceR`、`ChangeR`、`UserR` 等语义化类
5. **获取当前用户**：`request.getAttribute("uuid").toString()`
6. **分页查询**：使用 `PageRequestDto` 接收参数

### 3-B.2 响应类详解

```java
// response/J.java - 基础响应（尽量少用）
public class J {
    private int code;      // 0=成功, 1=失败
    private String msg;    // 消息
    private Object data;   // 数据
}

// response/ResourceR.java - 资源获取
public class ResourceR {
    public J resourceSuch(boolean isSuch, Object data);
    // code: isSuch?0:1
    // msg: "资源获取成功/失败"
}

// response/ChangeR.java - 变更操作
public class ChangeR {
    public J udu(boolean is, int type);  // type: 1=上传, 2=删除, 3=修改
}

// response/UserR.java - 用户错误
public class UserR {
    public J noSuchUser();                    // 用户不存在
    public J insufficientAccountPermission(); // 权限不足
    public J uuidMismatch();                  // UUID不匹配
}
```

## 六、关键实现细节

### 6.1 JWT 实现
- 使用 `jjwt` 库
- Token 包含用户 UUID
- 拦截器验证 Token 有效性

### 6.2 文件上传
- 使用 MinIO 存储私有文件
- 使用腾讯云 COS 存储公共文件
- 通过 `Apache Tika` 解析文件类型

### 6.3 多语言
- 学园、部团、学生支持中日韩英四国语言
- 存储为独立字段

### 6.4 分类树
- 使用 `parent_id` 实现树形结构
- 支持无限层级
- 通过递归查询获取子树

### 6.5 作品分类

## 八、开发规范（面向 AI）

### 8.1 后端规范
1. **Controller** 负责接收请求、参数校验、调用 Service
2. **Service** 负责业务逻辑
3. **Mapper** 负责数据库操作
4. **Model/POJO** 用于数据传输
5. **统一响应格式**：使用 `response/` 包下的类

### 8.2 前端规范
1. **Views** 只做页面布局和路由切换
2. **Components** 负责具体 UI 渲染
3. **Interfaces** 集中定义类型
4. **Stores** 管理全局状态
5. **Utils** 放置通用工具函数

### 8.3 API 设计规范
1. **RESTful 风格**：资源命名，复数形式
2. **GET**：查询
3. **POST**：新增/修改（通过 up_type 区分）
4. **认证**：Token 放在 Authorization header

### 8.4 数据库规范
1. **ID**：使用 String UUID
2. **时间**：使用 TIMESTAMP，ISO8601 格式
3. **软删除**：使用 status 字段标识
4. **索引**：外键字段建立索引
