# 作品详情页点赞能力 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为作品详情页补齐可落库的点赞/取消点赞能力，并在不破坏管理端 `like_count` 展示的前提下返回当前用户点赞状态。

**Architecture:** 后端新增 `work_like` 关系表与独立的点赞切换 Service/Controller，继续保留 `work.like_count` 作为聚合字段。详情接口 `/api/work/only` 维持公开访问，但在携带合法 token 时手动解析用户身份并补充 `liked_by_current_user`。前端仅修改作品详情页和相关 API/类型定义，不扩散到其他页面。

**Tech Stack:** Java 17、Spring Boot、MyBatis、Flyway、JUnit 5、Mockito、Vue 3、TypeScript、Axios、Ant Design Vue

- [ ] **Step 3: 实现 `WorkLikeService.toggleLike(...)` 的最小事务逻辑**

- 唯一键冲突 → 重新读取当前状态并返回，不让计数重复增加

- [ ] **Step 2: 新建点赞 API 帮助函数**

```ts
import { baseHttp } from "@/utils/https.ts"
import type { ResponseImpl } from "@/interfaces/ResponseImpl.ts"

export async function toggleWorkLike(workId: string, token: string): Promise<{ liked: boolean; like_count: number }> {
  const res = await baseHttp.post<ResponseImpl>(
    "/api/work/like/toggle",
    { work_id: workId },
    { headers: { Authorization: token } },
  )
  if (res.data.code === 0) return res.data.data
  throw new Error(res.data.msg || "点赞操作失败")
}
```
